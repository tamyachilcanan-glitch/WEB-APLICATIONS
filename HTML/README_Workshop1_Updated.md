# Workshop 1 - University Website

**Name:** Tamya Chilcañan 
**Course:** Web Applications 

## Description

In this workshop I created a simple university website using HTML. The website is divided into several pages connected through a navigation menu.

The purpose of the workshop was to practice the basic structure of HTML pages and use different HTML elements to organize information.

## Main HTML Structures Used

The website uses the basic HTML structure with `<!DOCTYPE html>`, `<html>`, `<head>` and `<body>`.

I also used:

- `<header>` and headings such as `<h1>`, `<h2>` and `<h3>` to organize titles and sections.
- `<nav>` and `<a>` to create the navigation menu and connect all the pages.
- `<main>`, `<section>` and `<article>` to organize the content of the home page.
- `<p>` for text and descriptions.
- `<ul>`, `<ol>` and `<li>` to create unordered and ordered lists.
- `<img>` to add my profile image.
- `<table>`, `<tr>`, `<th>` and `<td>` to create my weekly class schedule.
- `<form>`, `<input>`, `<select>`, `<textarea>` and `<button>` to create the contact form.
- External links using `<a href="">` with `target="_blank"`.

## Website Pages

- **Home:** Contains information about me, my degree program, semester, academic interests, and a profile image.
- **Courses:** Shows my university courses, instructors, main topics, and topics I expect to learn.
- **Schedule:** Shows my weekly university schedule using an HTML table.
- **Hobbies:** Contains activities that I enjoy in my free time.
- **Learning Resources:** Shows some resources I use to study and includes an external HTML tutorial.
- **Contact:** Contains a simple form with fields for name, email, date of birth, semester, reason for contact, message, and terms acceptance.

## Technologies Used

- HTML5
- Visual Studio Code
- Linux
- Apache Web Server

## What I Learned

In this workshop I learned how to create several HTML pages and connect them using relative links.

I also practiced how to organize information with headings, paragraphs, lists, sections, tables and forms. Another important part was learning how file paths work when linking pages and images located in different folders.

Finally, I tested the website using a web server to make sure the pages and navigation worked correctly.
